How does the Miner score Launches and set the day's soft threshold?

Each Featured Launch gets a fit from 0 to 10 against the Interest scope, judged on its own in a short run. Once the whole day is judged, plain code draws today's line: the fit of the day's N-th best Launch, where N grows with the day's Launch count, but never below a floor. Launches at or above the line get a Dossier; every other Launch gets a one-line Skip.

The Launches are real: every Featured Launch from Oct 11 to 14, 2026, read through the Product Hunt API. The fits are stand-ins. Claude judged them by hand against a draft Interest scope, as the Miner's model would. Change the settings, run the walkthroughs, and correct any fit that looks wrong.

    Fit bands

    Fixed in the Miner's prompt, so a fit means the same thing in every run and on every provider.

    9–10Squarely a Want, nothing in Don't want, and a Lean in its favour.
    7–8Clearly a Want.
    5–6Next to a Want, or a Want with a Lean against it.
    3–4Loosely related, or a Want that hits a Don't want.
    0–2In Don't want, or nowhere in the scope.

    What each judgment returns

    Through a schema-checked tool in our Pi extension. The model never writes "Dossier" or "Skip"; plain code adds that once the line is drawn.

    postIdProduct Hunt Post id.
    fitWhole number, 0–10, on the bands.
    notAProductNothing to use or sign up for: hardware, an announcement.
    noAccountThe Launch says it needs no account.
    reasonOne line: what it is, and how it meets the Interest scope. Read the same whichever way the line falls.
    rulesAppliedNames of the Rules it followed, shown on the line.
